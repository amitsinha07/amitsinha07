## About

I'm a backend engineer with 4+ years building distributed services in **Go, Java and Node.js** — the kind that move money, records and orders between systems that can't afford to lose them.

An increasing share of that work is putting **LLMs into production** rather than into demos: retrieval pipelines that cite their sources, MCP servers that give models real tools, and agentic workflows that replace multi-step manual processes.

Most recently that's meant national-scale infrastructure. At Wits Innovation Labs I architected the backend for an integration testing platform on India's ONDC network — thousands of organizations run their implementations against it before going live, across 20+ business domains. Before that, pension transaction systems and enterprise workflow orchestration.

> [!NOTE]
> I like problems where correctness matters more than shipping speed, and where you find out quickly if you got it wrong.

## Selected Work

### Network Integration Testing Platform
<sub><b>ONDC Workbench</b> · production · closed source</sub>

The system organizations test against before joining a national commerce network. I architected the backend: a domain-agnostic testing core that replays full protocol transactions, verifies cryptographically signed request/response pairs, and reports exactly where an implementation breaks the spec — extended to 20+ business domains without rewriting the core.

I also built the AI layer on it: a RAG pipeline over the protocol documentation so users debug by asking a question instead of searching a spec, and an MCP server that exposes the whole platform to any LLM for AI-assisted testing.

`Go` `Node.js` `React` `Microservices` `Kafka` `Kubernetes` `RAG` `MCP`

### Pension Transactions Backend
<sub><b>National Pension Scheme Portal</b> · production · closed source</sub>

Microservices in Go handling financial transactions and subscriber records, built fault-tolerant because the data underneath is somebody's retirement. Government API integration for real-time updates, two-factor authentication across sensitive flows.

`Go` `Microservices` `React` `2FA`

### Workflow Orchestration SaaS
<sub><b>Qurate</b> · production · closed source</sub>

Turned long, branching enterprise onboarding processes into managed workflows. Yugabyte for distributed storage, Kafka between steps, OpenTelemetry threaded end to end so a stalled workflow is traceable rather than mysterious.

`Go Fiber` `Yugabyte` `Kafka` `OpenTelemetry`

### Serverless Mobile Backend

Real-time data delivery to an iOS client on a fully serverless stack — AppSync and GraphQL at the edge, Lambda and DynamoDB behind it.

`AWS AppSync` `GraphQL` `Lambda` `DynamoDB`
